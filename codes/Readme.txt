# Reproducibility codes and trained models
The package supports vegetation index construction, fixed-split model reproduction at Sites 1 and 2, full-sample reconstruction at Site 2, and visualization of predictions generated by stacking models.

## Repository structure
codes/
├── Readme.txt
├── Calculate_vegetation_indices_for_different_band_combinations.m
├── plot_stacking_results_with_intervals.m
├── Site 1 Fixed-split comparison/
│   ├── models/                         # 30 trained final models
│   ├── reproduce_site1.py
│   └── requirements.txt
├── Site 2 Fixed-split comparison/
│   ├── final_models.joblib             # trained LPU, SPU, and GPU models
│   ├── reproduce_site2.py
│   └── requirements.txt
└── Site 2 Full-sample reconstruction/
    ├── 0.3-*.mat ... 0.9-*.mat       # saved stacking models for LPU/SPU/GPU
    ├── Stacking_prediction.m
    └── Readme.txt

## Software requirements
### Python workflows
Install the packages specified in the `requirements.txt` file inside each Python workflow folder.
### MATLAB workflows
MATLAB is required for the `.m` scripts and saved `.mat` models. The Statistics and Machine Learning Toolbox is required, together with any toolbox needed by the learner objects stored in the supplied `.mat` files.
